## 🍭 Welcome to the World of Shinchan!

> *"Why be normal when you can be legendary?"* 🕺

What happens when a developer's portfolio meets the mischievous universe of **Shinchan Nohara**?

You get a playful, immersive web experience that brings together **3D visuals, colourful anime-inspired aesthetics, interactive elements, and a little childhood nostalgia.**

This isn't your usual corporate portfolio. It's a digital playground designed to make exploring a website feel like an adventure.

🎨 **The idea:** Turn a personal portfolio into an experience people actually want to explore.

🌐 **The result:** A multi-page website with playful visuals, navigation, projects, an about section, and a contact page.

## ✨ Features That Make It Special

### 🎨 01. Anime-Inspired Visual Identity

A vibrant interface inspired by Shinchan's colourful world, with playful details and a personality of its own.

### 🧊 02. Interactive 3D Experience

A Three.js-powered visual experience designed to add depth and movement to the website.

### 🧭 03. Multi-Page Navigation

Explore four dedicated pages, each with its own purpose:

* 🏠 Home
* 👦 About Me
* 🎮 Projects
* 💌 Contact

### 📱 04. Responsive Design

Responsive styling and a mobile navigation menu help the experience adapt to different screen sizes.

### 💌 05. Contact Form Interaction

Client-side form validation with simulated success feedback. The current implementation is frontend-only and does not send real emails.

### ⚡ 06. Lightweight Frontend

Built with standard web technologies and CDN-hosted libraries, without requiring a complex backend or build pipeline.

## 🚀 Run It Locally

Want to explore the project or make your own modifications?

No complicated setup. Just follow these steps!

### 1. Clone the repository

```bash
git clone https://github.com/metadore/shinchan-portfolio.git
```

### 2. Enter the project directory

```bash
cd shinchan-portfolio
```

### 3. Launch the website

Open `index.html` in your browser.

**Recommended:** Use the Live Server extension in Visual Studio Code for a smoother local development experience.

### 4. Start experimenting!

Change the colours, customise the pages, experiment with animations, or add your own projects.

**Warning:** Excessive creativity may result in spontaneous Shinchan dancing. 🕺

## 🎨 The Design Philosophy

This project follows one simple principle:

### A portfolio should be an experience, not just a list of achievements.

The design brings together:

* 🌈 **Playfulness** — Bright, energetic visuals.
* 🧸 **Nostalgia** — A tribute to a beloved childhood character.
* 🌀 **Movement** — 3D visuals and interactive behaviour.
* 🧩 **Exploration** — Multiple pages with distinct purposes.
* 💡 **Creativity** — A personal twist on the traditional portfolio.

The goal is to combine personality and technology without losing the website's usability.
